# Plan: Open Questions And Risk Register

## Goal

PRD에서 확정되지 않은 결정과 위험한 가정을 구현 전에 추적합니다. 이 문서는 구현 작업 자체가 아니라 다른 MVP 계획의 결정 대기열입니다.

## Risks

- Whisper STT가 전문 용어, 한국어+코드 혼합 강의에서 오인식할 수 있습니다.
- STT 오류가 학습 노트 생성 단계까지 전달되면 잘못된 본문이 만들어질 수 있습니다.
- LLM API 비용이 긴 강의와 반복 생성에서 급증할 수 있습니다.
- 청크 경계가 부적절하면 RAG 답변의 근거가 끊길 수 있습니다.
- OCR은 화면 변화가 많은 코드 강의에서 비용과 중복이 커질 수 있습니다.
- LLM이 원본에 없는 내용을 본문에 섞어 넣으면 노트 신뢰도가 떨어집니다.
- 구어체를 과도하게 문어체로 바꾸면 강사의 뉘앙스와 중요한 강조가 사라질 수 있습니다.
- 맥락 기반 오탈자 교정이 멀쩡한 단어를 바꾸는 false positive가 발생할 수 있습니다.
- 저작권이 있는 강의 자료를 외부 API로 전송하거나 공유하는 데 법적/계약상 제한이 있을 수 있습니다.

## Steps

- [x] UI와 백엔드 실행 형태의 초기 방향을 정한다.
- [x] 외부 API 전송 범위의 초기 경계를 정한다.
- [x] 능동학습 기능 우선순위를 정한다.
- [ ] 비용 한도와 BYOK 정책을 결정한다.
- [ ] 확정된 항목을 관련 문서와 계획에 반영한다.

## Validation

- 각 구현 계획 시작 전에 관련 open question이 구현을 막는지 확인합니다.
- 결정된 질문은 관련 문서와 필요 시 ADR로 옮깁니다.

## Result

초기 결정 7개를 반영했습니다. 남은 질문은 챕터 자동 분할, speaker mode, 긴 화면 메모 처리, 중간 confidence 교정 후보 정책입니다.
