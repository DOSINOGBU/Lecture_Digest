# Plan: Random Quiz Generation

## Goal

승인된 학습 노트와 출처 매핑을 기반으로 사지선다형과 서술형 퀴즈를 생성하고, 사용자에게 랜덤으로 출제할 수 있게 설계합니다.

## Scope

- 퀴즈 입력은 승인된 Markdown 노트와 원본 segment mapping입니다.
- 문제 유형은 사지선다형과 서술형을 지원합니다.
- 출제 시 두 유형이 랜덤으로 섞여 나옵니다.
- 각 문항은 문제, 보기, 정답, 해설, 출처를 포함합니다.
- 출처 없는 문항은 확정 산출물로 저장하지 않고 `flagged`로 남깁니다.

## Out Of Scope

- Anki 카드 생성.
- 점수화/학습 통계.
- 모바일 복습 앱.
- 개념 그래프 기반 적응형 출제.

## Assumptions

- 퀴즈는 Anki 이후 후속 기능입니다.
- 사지선다형은 정답 1개와 오답 보기 3개를 기본값으로 둡니다.
- 서술형은 채점 자동화보다 해설과 출처 제공을 우선합니다.

## Steps

- [ ] 퀴즈 입력 소스와 필수 출처 필드를 정의한다.
- [ ] 사지선다형 문항 스키마를 정의한다.
- [ ] 서술형 문항 스키마를 정의한다.
- [ ] 랜덤 출제 정책과 재현 가능한 seed 처리 여부를 정한다.
- [ ] 문항 품질 검수 기준을 만든다.

## Validation

- 객관식과 서술형이 섞여 출제됩니다.
- 모든 문항은 출처 timestamp를 포함합니다.
- 사지선다형은 보기 4개와 정답 1개를 포함합니다.
- 서술형은 기준 답안 또는 해설을 포함합니다.
- 출처 없는 문항은 `flagged`로 남습니다.

## Risks

- 오답 보기가 부정확하면 오히려 학습 혼란을 만들 수 있습니다.
- 서술형 자동 채점까지 확장하면 평가 기준 설계가 필요합니다.

## Result

진행 전입니다.
