# Plan: Lecture Ingestion And Transcript Pipeline

## Goal

강의 파일과 선택 자막을 등록하고, 자막 파싱 또는 STT로 시간축 세그먼트를 생성하는 MVP 첫 파이프라인을 구현합니다.

## Scope

- 강의 등록 입력: 영상 파일, 선택 자막, 제목, 강사, 카테고리.
- `lecture_id`와 처리 상태 생성.
- SRT/VTT 파싱과 타임스탬프 보존.
- 자막이 없을 때 STT 작업으로 전환.
- 세그먼트 없음, 오디오 없음, 파싱 실패 오류 처리.

## Out Of Scope

- OCR과 화자 분리.
- RAG, 요약, 학습 노트 생성.
- 클라우드 업로드와 멀티 사용자 권한.

## Assumptions

- MVP 실행 방식은 Streamlit 추천이며, 파이프라인은 초기 단일 CLI/단일 프로세스로 시작합니다.
- 저장소는 로컬 중심으로 두며, 구체 구현은 로컬 파일/SQLite 조합 중 구현 전에 확정해야 합니다.
- STT 모델은 Whisper `large-v3` 또는 faster-whisper 후보로 두되 의존성 추가 전 승인과 비용/성능 설명이 필요합니다.

## Steps

- [x] 등록 입력 스키마와 필수/선택 필드를 정의한다.
- [x] 지원 파일 형식과 오류 메시지를 정한다.
- [x] 자막 파서 출력 형식을 `segments`로 고정한다.
- [x] 자막 없음 → STT 작업 상태 전환을 설계한다.
- [ ] STT 결과를 SRT 호환 세그먼트로 저장한다.
- [x] 실패 단계와 재시도 가능 여부를 기록한다.

## Validation

- 자막이 있는 강의는 STT를 건너뛰고 세그먼트 타임스탬프를 보존합니다.
- 자막이 없는 강의는 STT 단계로 전환하고 예상 처리 상태를 보여줍니다.
- 세그먼트가 없으면 이후 노트 생성을 막는 명확한 오류를 반환합니다.

## Risks

- 한국어+전문 용어 STT 오인식이 후속 노트 품질에 전파될 수 있습니다.
- 영상 파일이 크면 로컬 처리와 UI 응답성이 떨어질 수 있습니다.

## Result

표준 라이브러리 기반으로 강의 등록, SRT/VTT 파싱, 자막 없음 STT 대기 상태, JSON 저장, CLI 빈/진행/오류 상태를 구현했습니다. 실제 STT 실행은 새 의존성과 모델 선택이 필요하므로 후속 작업으로 남깁니다.
