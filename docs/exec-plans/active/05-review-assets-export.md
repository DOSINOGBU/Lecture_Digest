# Plan: Flashcards, Quizzes, And Export Assets

## Goal

챕터 요약, 세그먼트, 학습 노트를 기반으로 Anki 카드를 먼저 생성하고 출처 매핑을 보존합니다. 자동 퀴즈는 Anki 이후 후속 기능으로 확장합니다.

## Scope

- Cloze, Q&A, 코드 카드 후보 생성.
- `.apkg` 또는 AnkiConnect 내보내기 후보 검토.
- 퀴즈는 후속 범위로 두되, 출처 매핑 규칙은 Anki와 공유할 수 있게 설계.

## Out Of Scope

- 퀴즈 생성 구현.
- 개념 그래프.
- Notion/HTML/PDF 렌더러.
- 모바일 복습 앱.

## Assumptions

- Anki를 퀴즈보다 먼저 출시합니다.
- 카드와 후속 퀴즈는 원본 출처가 없는 경우 확정 산출물로 저장하지 않습니다.

## Steps

- [ ] Anki 카드 입력 소스 우선순위를 정한다.
- [ ] 출처 매핑 필수 필드를 정의한다.
- [ ] 내보내기 형식과 실패 상태를 정의한다.
- [ ] 표본 검수 기준을 만든다.

## Validation

- Anki 카드 유효성은 직접 검수 기준 80% 이상을 목표로 합니다.
- 후속 퀴즈 문항은 문제, 보기, 정답, 해설, 출처를 포함해야 합니다.
- 출처 매핑이 없는 카드/후속 퀴즈는 `flagged` 또는 검수 대기로 남깁니다.

## Risks

- 너무 이른 퀴즈 구현은 핵심 파이프라인 안정화보다 우선순위를 흐릴 수 있습니다.
- 부정확한 카드와 퀴즈는 잘못된 기억을 강화할 수 있습니다.

## Open Questions

- `.apkg` 파일 생성과 AnkiConnect 중 어떤 방식을 우선할 것인가?
