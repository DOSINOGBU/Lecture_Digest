# Plan: Phase 0 Baseline Validation

## Goal

보유 강의 1개와 1챕터를 기준으로 NotebookLM, 단일 LLM 호출, 수동 골든 노트를 비교해 LectureDigest가 직접 구현해야 할 차별 영역을 확인합니다.

## Scope

- 샘플 강의와 챕터 1개 선정.
- 원본 대본 또는 자막 확보.
- 수동 골든 노트 작성 기준 정의.
- 비교 항목: 요약 품질, 출처 정확도, 누락 개념, 비용/시간, 노트 가독성.

## Out Of Scope

- 자동 파이프라인 구현.
- UI 구현.
- 대량 강의 처리.

## Steps

- [ ] 샘플 강의 선정 기준을 정한다.
- [ ] 원본 대본, 자막, OCR 필요 여부를 확인한다.
- [ ] 수동 골든 노트의 최소 구조를 정한다.
- [ ] NotebookLM과 단일 LLM 결과를 생성한다.
- [ ] PRD 성공 기준에 맞춰 차이와 리스크를 기록한다.
- [ ] 직접 구현 범위 축소/유지 판단을 남긴다.

## Validation

- 비교표에 출처 정확도, 누락 개념, 환각 여부, 노트 길이, 처리 시간을 기록합니다.
- 직접 개발해야 할 항목과 외부 도구로 충분한 항목을 분리합니다.

## Risks

- 기존 도구가 충분히 좋으면 직접 구현 범위를 줄여야 할 수 있습니다.
- 샘플 강의 1개가 전체 도메인을 대표하지 못할 수 있습니다.

## Open Questions

- 샘플 강의는 어떤 도메인과 난이도로 선택할 것인가?
- 골든 노트 작성자는 누구이며 어떤 품질 기준을 적용할 것인가?

## Result

진행 전입니다.
