# Cost

## MVP Cost And BYOK Policy

- MVP는 BYOK(Bring Your Own Key)를 기본으로 둡니다. 사용자는 본인 OpenAI API 키와 제공자 계정의 예산/쿼터를 사용합니다.
- 앱은 API 키 값을 저장소, 산출물, 로그, 테스트 fixture에 저장하지 않습니다. 키는 환경 변수나 로컬 비밀 저장소에서만 읽습니다.
- 유료 클라우드 호출은 사용자가 명시적으로 실행한 CLI 명령 또는 이후 UI 버튼에서만 발생합니다.
- 자동 백그라운드 재처리와 모델/prompt 변경에 따른 자동 재생성은 하지 않습니다. 기존 산출물은 stale로 표시하고 수동 재생성 시에만 비용이 발생합니다.
- STT, Vision OCR, LLM 호출은 provider, model, prompt_version, 입력 크기, 처리 시간, 상태, 가능하면 비용 추정치를 기록합니다.
- 앱 레벨 월간/강의별 hard budget은 아직 확정하지 않습니다. 클라우드 배포나 공유 계정 모드가 생기면 별도 ADR에서 예산 상한, rate limit, 차단 정책을 정합니다.

LectureDigest는 STT, OCR, 임베딩, LLM 요약/RAG/노트 생성처럼 비용이 강의 길이와 반복 실행에 비례하는 작업이 많습니다. 비용 관련 결정은 품질과 재현성을 해치지 않는 범위에서 캐시, 저비용 모델, 제한된 재시도를 우선합니다.

초기 비용 경계는 로컬 처리 중심과 클라우드 LLM 호출로 나눕니다. STT/OCR/파일 보관/캐시는 로컬 비용으로 보고, 외부 API 비용 관리는 LLM 호출에 집중합니다.

## Budgets

| 영역 | 예산/목표 | 경고 기준 | 소유자 |
|---|---|---|---|
| RAG 질의 | 일반 질의 30초 이내, 과도한 rerank 제한 | 답변 지연 또는 반복 호출 증가 | 미정 |
| ScriptDigest 챕터 노트 | 30분 챕터당 LLM 비용 $0.30 이하 목표 | 재시도/긴 입력으로 목표 초과 | 미정 |
| STT | 영상 길이 0.3배 이하 처리 목표 | GPU 처리 시간 또는 API 비용 급증 | 미정 |
| OCR | 키프레임/중복 제거 후 호출 | 화면 변화 많은 강의에서 호출 수 급증 | 미정 |
| 임베딩 | 같은 입력 반복 호출 금지 | 캐시 미사용 또는 재생성 반복 | 미정 |

## Model Routing Principles

- L1 섹션 요약과 대량 호출은 `gpt-4o-mini` 등 저비용 모델을 우선합니다.
- L2/L3 요약, RAG 최종 답변, ScriptDigest rewrite/보강처럼 품질이 중요한 단계는 `gpt-4o` 또는 `gpt-4.1` 등 고품질 모델 후보를 사용합니다.
- STT 무결성 보정은 검출 패턴에 매칭된 세그먼트만 LLM 호출합니다.
- Cleanup 기본 작업은 규칙 기반을 우선하고 필요한 경우에만 LLM을 호출합니다.
- OCR은 장면 변화 기반 키프레임과 중복 제거 후 수행합니다.
- 임베딩과 LLM 호출 결과는 캐시하여 같은 입력을 반복 호출하지 않습니다.
- 모델 또는 prompt 변경으로 산출물이 stale 상태가 되어도 자동 재생성하지 않고, 사용자가 수동 재생성 버튼을 눌렀을 때만 비용이 발생하게 합니다.

## Cost Review

- 새 외부 API나 LLM 호출을 추가할 때 예상 호출량, 입력 크기, 재시도 정책을 기록합니다.
- 비용이 사용자 행동에 비례하면 rate limit, quota, 비용 상한을 검토합니다.
- 반복 작업 자동화는 실행 빈도와 실패 재시도 비용을 함께 봅니다.
- 모델/프롬프트 변경으로 캐시가 무효화될 때 재생성 비용을 추정합니다.
- 로그에는 토큰 사용량, API 비용 추정, 처리 시간을 남기되 민감한 원문은 남기지 않습니다.
