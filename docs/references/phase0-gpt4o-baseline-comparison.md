# Phase 0 GPT-4o Baseline And Comparison

이 문서는 Phase 0 비교 산출물입니다. 원본 영상, 전체 자막, 전체 로컬 경로, API key는 저장하지 않습니다.

## Retention Policy

| 자료 | 저장소 포함 여부 | 기준 |
|---|---|---|
| gpt-4o baseline | 포함 | 원본 대본을 그대로 싣지 않고 생성 결과와 실행 메타데이터만 기록 |
| 비교표 | 포함 | 제품 판단과 후속 구현 범위 결정에 필요 |
| 골든 노트 | 일부 샘플만 포함 | 사람 승인 후 대표 샘플만 저장 |
| 원본 데이터 | 제외 | 영상, 전체 SRT/STT, OCR 원문, 전체 로컬 경로는 저장하지 않음 |

## Baseline Draft Summary

gpt-4o baseline은 브라우저 동작 원리, 하이레벨/로우레벨 구분, 렌더링 엔진, 브라우저 엔진 차이, `caniuse.com` 활용을 핵심 학습 목표로 뽑았습니다. TL;DR과 개념 노트는 짧고 읽기 쉬웠지만, DOM/렌더 트리/호환성 설명이 학습 노트로 쓰기에는 얕았습니다.

Anki 후보는 질문 형태로 생성됐으나 답변이 없어 바로 카드로 전환하기 어렵습니다. 화면/OCR 필요 항목은 감지했지만 구체 화면 근거가 `??`로 남아 있어 승인 기준을 통과하지 못했습니다.

## Approval Criteria

사람이 AI 초안을 골든 노트로 승인하려면 아래 조건을 모두 만족해야 합니다.

승인 담당자는 사용자 본인이며, AI 초안 생성 후 사용자가 승인한 대표 샘플만 저장소에 포함합니다. 현재 gpt-4o baseline 초안은 아래 기준을 충족하지 못해 골든 노트 샘플로 확정하지 않습니다.

| 기준 | 승인 조건 |
|---|---|
| 출처 연결 | 모든 주요 주장과 카드 후보가 타임스탬프 또는 segment id에 100% 연결됨 |
| 핵심 개념 | DOM, 렌더링 흐름, HTML/CSS 처리, 브라우저 호환성 등 핵심 개념 누락 없음 |
| 환각 | 원본에 없는 정보를 원본처럼 쓰지 않음. 필요한 부연은 `(추론)`으로 표시 |
| OCR 표시 | 화면 자료가 필요한 부분이 명확히 표시됨 |
| OCR 해상도 | OCR은 영상 원본 해상도인 1920x1080 프레임에서 수행되어야 함 |
| Anki 전환성 | 질문과 답변, 출처가 함께 있어 Anki 카드로 바로 전환 가능 |

## OCR Status

대표 프레임 3개는 1920x1080으로 추출되어 원본 해상도 확인은 완료했습니다. 실제 OCR은 아직 수행하지 않았습니다. 현재 로컬 환경에서 `tesseract` 명령을 찾지 못했기 때문에, OCR 단계가 도입되면 원본 1920x1080 프레임으로 다시 실행해야 합니다.

## Comparison

| 항목 | gpt-4o baseline 관찰 | LectureDigest 구현 판단 |
|---|---|---|
| 출처 정확도 | 주요 개념에 시간 범위가 붙었지만 일부 화면 근거는 `??`로 남음 | segment id와 타임스탬프를 강제하는 구조 유지 |
| 누락 개념 | 큰 흐름은 잡지만 DOM/렌더 트리/호환성 등 세부 설명이 얕음 | 계층 요약과 챕터 노트 검증 게이트 필요 |
| 환각 | 명백한 새 사실 추가는 적지만 화면 근거는 추론과 출처가 섞일 위험 있음 | OCR 원문/정제본 분리와 `(추론)` 표기 유지 |
| 화면 의존 처리 | 화면 자료 필요성을 감지했지만 어떤 화면인지 구체 매핑이 부족함 | OCR/프레임 근거를 별도 payload로 보존 |
| 노트 가독성 | 짧고 읽기 쉽지만 학습 노트로는 설명량이 부족함 | ScriptDigest에서 구조화와 문어체 rewrite 필요 |
| 복습 전환성 | Anki 후보는 생성되지만 답변이 없어 바로 카드화하기 어려움 | Anki 우선 구현 유지, 카드 품질 검수 필요 |

## Decision

단일 gpt-4o 호출만으로는 출처 정확도, 화면 근거 처리, 검증 가능한 학습 노트, Anki 전환성 요구를 충분히 만족하지 못했습니다. 따라서 Phase 1의 직접 구현 범위는 축소하지 않고 유지합니다.
